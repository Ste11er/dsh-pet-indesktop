## 评估验收表

| 评估项 | 通过标准 |
|---|---|
| 额度字段 | 服务端含义、单位、缺失/不限量与过期状态均有来源；不把 credits 换算成无依据的消息数 |
| UI 价值 | 明确放在哪个现有界面、解决什么问题；若要持久设置，给出设置门禁准入材料 |
| token 刷新 | 写清是否支持、谁拥有凭据与并发更新；没有可靠宿主契约就保留重新登录方案 |
| 代理和失败 | 对齐现有网络策略，区分缺凭据、过期与网络失败，不把失败显示成零额度 |
| 决策输出 | 更新研究档，列出采用/暂缓的依据；没有把研究假设写成已实现能力 |

若需要验证解析或缓存假设，复用 `tests/test_chatgpt_quota.py` 与
`tests/test_subscription_quota_ui.py`；评估本身不必改产品或新增测试。
若做真实只读查询，记录请求次数、延迟、缓存命中与网络环境，输出不含身份或 token；
未实测则如实注明，不重复使用历史延迟当作当前证据。
未来落地如涉及共享配置或线程，按总表跑全量并补三份 PR 证据。
