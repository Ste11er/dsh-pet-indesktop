## 验收矩阵

| 场景 | 通过标准 |
|---|---|
| 完成/失败同时由状态链和事件链到达 | 只呈现一次，由明确的单一语义入口负责 |
| Report Gate = 0 / 1 | 0 不出该类气泡，1 出一次；事件记录和检测均保留 |
| 审批/问题未解决时出现普通状态 | 常驻交互优先，不被普通反馈覆盖或解除 |
| 多会话交错、重复事件、旧事件重放 | 不串会话，不把已完成轮次再次播报 |
| 未发现缺口 | 交付覆盖证据和结论，不为了“每态都有气泡”增加噪声 |
