## 目标与现状

让 JS 桥接写入位置与 Python 消费位置遵循同一公式，消除自定义配置目录下的静默零事件。
[插件 `bridgeDir()`](../../integrations/dsh-pet-bridge/index.js) 在 POSIX 使用固定 `.config`；
[配置 `_default_base()`](../../pet/config.py) 会 trim 并读取 `XDG_CONFIG_HOME`；
[状态跟踪器](../../pet/dsh_state.py) 从配置目录的父目录定位桥目录。
还需核对 [控制通道](../../pet/dsh_control.py) 等读写者，避免只对齐一条事件路径。

## 验收与测量

| 输入环境 | 预期 |
|---|---|
| Linux 未设置、空串、纯空白 XDG | 双方回退到用户目录下 `.config/dsh-pet-bridge` |
| Linux 自定义绝对路径，含空格或非 ASCII 字符 | 双方均指向该路径下 `dsh-pet-bridge` |
| Windows/macOS | 原有平台公式不变；记录平台分支回归结果 |
| 两进程继承不同环境 | 能从记录中定位差异，不能宣称单侧设置变量即可生效 |

相对路径等现有边界按当前 Python 行为先锁定；若要改变语义，应另行说明迁移影响。
